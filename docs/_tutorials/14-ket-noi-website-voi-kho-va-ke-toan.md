## Mục tiêu bài viết

Khép kín quy trình: khách đặt hàng trên website → tự động trừ kho → tự động xuất hoá đơn.

## Nội dung cần có

- [ ] Bật eCommerce trên Website đã build ở bài trước
- [ ] Liên kết sản phẩm Website với Inventory (số lượng tồn hiển thị đúng)
- [ ] Cấu hình quy trình xác nhận đơn hàng tự động vs cần duyệt thủ công
- [ ] Tự động tạo Invoice khi đơn hàng thanh toán thành công
- [ ] Cổng thanh toán online phổ biến ở VN (VNPay, Momo, chuyển khoản...) — mức độ hỗ trợ sẵn có
- [ ] Theo dõi đơn hàng online trong Sales/Inventory như đơn hàng thường
